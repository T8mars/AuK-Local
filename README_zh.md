# AuK Local Windows 本地整合包

AuK Local 是由 T8star-Aix 维护的独立 Windows 浅色中文工作台，支持 AuK 的语音生成、编辑、增强和分离。它与 ComfyUI 节点是两个独立程序：本地整合包通过 `AuK-Local.exe` 启动，ComfyUI 节点直接运行在 ComfyUI 进程内。

## 下载与启动

**完整版下载（包含模型和 Python）：[Hugging Face 海外直链 — AuK-Local.rar](https://huggingface.co/t8star/Auk-Comfy/resolve/main/AuK-Local.rar?download=true)**，大小 20.37 GB（18.97 GiB）。下载中断时可使用支持断点续传的下载工具继续。完整解压后，双击 `AuK-Local` 文件夹中的 `AuK-Local.exe`。

SHA-256：`a99966c3eb7336ca9d027c0ea491edaddcfa3582b2eb436444a36cfc2f2e9061`

GitHub Release 提供的是**不含模型、不含 Python 的程序更新包**。它适合覆盖到已有完整版中，不能单独完成推理。

1. 完整解压 AuK Local，保留原有目录结构。
2. 双击根目录的 `AuK-Local.exe`。
3. 保持控制台窗口开启；服务就绪后会自动打开 `http://127.0.0.1:7860`。
4. 页面顶部有醒目的“检查更新”和“立即更新并重启”按钮。

描述生成与声音克隆默认自动估算目标文本的说话时长，避免短句沿用过长时长后在结尾读出内部提示词；关闭自动估时后可手动指定。默认模型是高质量的 AuK Base，AuK-Flash 适合快速预览。音高、音量、音色、去口音、耳语、增强、音质修复和分离与实际输入音频等长；速度编辑按“输入时长 ÷ 速度倍率”计算；情绪编辑使用官方系数：悲伤 ×1.22、恐惧 ×1.16、其他支持情绪 ×1.06；文字和歌词编辑按本次增删文字比例估算；非语言声音编辑按事件类别增减官方时长。默认勾选“每次使用随机 Seed（抽卡）”，关闭后可填写固定 Seed 来复现结果。任务运行期间状态区每秒刷新真实阶段、实际 Seed 和已用时间。模型默认在首次成功生成后常驻，使用同一模型和 CPU Offload 设置的后续任务无需重新加载；高级参数中也可选择每次生成后释放，或点击“立即释放已加载模型”手动清理显存。

网页音频组件支持两种截取方式。使用波形时，先拖选范围，点击右下角剪刀，再点击播放器出现的 **Trim** 确认；页面的“实际提交输入”会立即变为剪裁后的秒数。也可以设置“截取开始/结束”并点击 **应用截取**。两种方式都直接替换当前待处理音频，后续预算和提交只读取已应用的片段；点击剪刀左侧的 **↶** 可恢复最初上传音频，清除后可以重新上传其它音频。

## 任务选择与官方格式

选择任务类型后，页面会立即显示该任务的音频要求、合法取值、官方填写格式、示例和注意事项。文字编辑和歌词编辑一次只能改一处；参考声音克隆只填目标文本，不能把参考音频原文或声音描述附加给模型。

| 任务 | 输入音频 | 主要输入示例 |
|---|---:|---|
| 描述生成语音 | 否 | 目标文本“欢迎回来”；声音描述“年轻女生，温柔、语速稍慢” |
| 参考声音克隆 | 是 | `大家好，欢迎收看今天的节目。` |
| 语音文字编辑 | 是，普通说话 | `把“今天下午开会”改成“明天上午开会”`；也支持单次插入或删除 |
| 歌词编辑 | 是，必须是无伴奏、隔离干净的独唱（a cappella） | `把歌词“明天你好”改成“未来你好”` |
| 音高编辑 | 是 | `+1` 或 `-2`，只支持 ±1/±2/±3 半音 |
| 速度编辑 | 是 | `0.75` 或 `1.25`，只支持 0.5/0.75/1.25/1.5/2.0 倍；目标时长强制按输入时长 ÷ 倍率计算 |
| 音量编辑 | 是 | `+5` 或 `-10`，只支持 ±5/±10/±15 分贝 |
| 情绪编辑 | 是，普通说话 | `开心`；限开心、愤怒、悲伤、恐惧、惊讶、厌恶、平静、兴奋；时长按官方情绪系数计算 |
| 音色编辑 | 是，普通说话 | `低沉磁性的年轻男声` |
| 去口音 | 是，普通说话 | `去掉方言口音，转换成标准普通话` |
| 非语言声音编辑 | 是 | `在“欢迎回来”后增加笑声` |
| 耳语转换 | 是，普通说话 | `转换成耳语` 或 `转换成正常说话` |
| 语音增强 | 是，普通说话 | `去噪并去除房间混响` |
| 音质修复 | 是，普通说话 | `补充高频并提升清晰度` 或 `去掉电话感` |
| 说话人分离 | 是，多人说话 | `第一个开始说话的人` |
| 音乐人声提取 | 是，混合音频 | `只保留歌声，去掉说话和伴奏` |
| 指定说话人提取 | 是，多人说话 | 填写目标说话人确实讲过的一小段内容 |

输入音频和目标输出分别最多 30 秒，二者不相加计算；例如 30 秒输入可以生成 30 秒输出。所有自动时长模式都会使用当前实际输入的精确值，即使滑块只显示一位小数，提交值仍保留精度。情绪、去口音和耳语必须使用普通说话；歌声会显著削弱这些任务的效果，已经是标准普通话的音频也不能用于验证去口音。

历史记录最多显示最近 50 项。单击一行即可回听当时的生成结果和参考/待处理音频，并查看原始填写内容、最终发送给模型的指令以及完整运行参数；失败、取消和重启中断的任务仍可按原参数重试。历史音频文件被手动删除或损坏时，界面会明确标记为不可播放。

如果 Chrome 的下载链接被安全策略拦截，可点击“保存本次结果到下载文件夹”，或选中历史记录后点击“保存选中的历史结果到下载文件夹”。程序会复制已有的本地 WAV 到 Windows 下载目录，并核对 SHA-256；不会覆盖已有文件。“打开输出文件夹”可直接取得原始结果。

编辑任务优先使用随程序代码提供的 Silero VAD 检测未加缓冲的真实语音区间，再只为模型输入补 0.1 秒边缘；耳语转换按官方 -44.47 LUFS 标定，歌词编辑和音乐人声提取按官方 -14 LUFS/0.95 峰值保护输出。运行参数会记录实际 VAD 与响度路径，便于判断是否发生降级。

自动更新会验证 RSA 数字签名、ZIP 文件 SHA-256 和包内每个文件的 SHA-256。安装前会备份旧程序，任何复制或校验失败都会回滚。更新器只替换白名单中的程序、脚本、界面和说明文件，明确禁止修改这些目录：

- `models`：模型权重
- `runtime`：便携 Python、CUDA 和 FFmpeg
- `ckpts`：用户放置的检查点
- `data`：任务记录、令牌和更新状态
- `outputs`：生成结果
- `logs`：运行日志

更新时必须先等待正在运行或排队的任务结束。为保证更新后能自动启动，请通过 `AuK-Local.exe` 启动，不要从服务 BAT 入口执行一键更新。

如果现有 0.2.2 在下载更新后没有自动重启，请手动解压 0.2.3 的代码更新包覆盖一次。0.2.2 的 Windows 启动脚本可能无法把已暂存的更新交给独立更新器；从 0.2.3 起，这一交接流程已通过真实升级和重启验证。
