# AuK Local 0.2.4

- 修复网页波形剪刀只改变播放器显示、没有同步到模型实际输入的问题。框选后点击剪刀并确认 Trim，“实际提交输入”会立即变为剪裁后的时长。
- 修复上方波形剪裁后再用“应用截取”时多个组件同时显示“错误”的问题。
- 自动估算超过 30 秒时，仍显示真实估算值和“已超出限制”，但不再把越界值写入 0.2–30 秒滑块导致 Gradio 整个事件失败。
- 清除音频会重置截取范围、输入时长和预算状态，可以立即换另一段音频。
- 浏览器真实验证覆盖：波形剪刀 2.08 秒 → 0.52 秒；再次明确截取 0.52 秒 → 0.25 秒；清除后重新上传恢复为 2.08 秒，全程没有组件错误。
