# AuK Local 0.2.5

- 新增本机保存按钮：当前与历史 WAV 可直接保存到 Windows 下载文件夹，逐份核对 SHA-256 且不覆盖已有文件；浏览器拦截下载时也可使用“打开输出文件夹”取得原始结果。

- 模型首次成功加载后默认常驻；同一模型与 CPU Offload 设置的后续任务会直接复用，避免每次等待 2–3 分钟。
- 高级参数新增“每次生成后释放”策略和“立即释放已加载模型”按钮；任务运行中会拒绝手动释放，避免破坏正在生成的结果。
- 历史记录扩展到最近 50 项，单击任意一行即可回听生成结果和参考/待处理音频，并查看当时填写的内容、最终模型指令和完整请求/元数据。
- 历史文件缺失或校验失败时会明确标记，不会把损坏的参考音频送到播放器。
- 修复 Python 3.10 下 Gradio 历史行点击事件参数无法注入的问题；损坏的历史 WAV 会显示状态并保留提示词详情，避免整个事件失败。
- 历史详情新增独立取消按钮，回听旧音频不会替换正在生成的结果。
- 裁剪提示补充原生 ↶ 恢复入口；不增加重复按钮，用户可在连续裁剪后直接恢复最初上传音频。

验证：163 项自动测试全部通过，Ruff 检查通过。实际浏览器已验证历史结果与参考音频播放、当前/历史结果本机保存（SHA-256 一致）和运行中拒绝手动释放。四次 Flash 真实生成均成功：首次加载 44.45 秒；常驻复用加载 0.00 秒，总耗时由 66.7 秒降至 22.9 秒；手动释放后重新加载 29.01 秒；每次生成后释放策略下，下一次重新加载 31.18 秒。上述时间来自 RTX 5090 Laptop 24GB 本机，仅作为这次实测记录。
