# AuK Local 0.2.3

- 输入音频与目标输出改为分别限制 30 秒，不再错误要求二者合计不超过 30 秒；30 秒输入可对应 30 秒输出。
- 修复 Windows 启动器环境变量大小写冲突，并强制 BAT 使用 CRLF，保证更新暂存后能交给独立更新器安装和重启。
- 自动编辑任务在服务端忽略残留的目标时长，并根据裁剪后实际提交的语音重新计算；4 秒输入不再沿用 48 秒旧值。
- 使用与 AuK Prompt Enhancer 相同的 Silero VAD 未加缓冲语音区间计算时长，只在送入模型时保留 0.1 秒边缘。
- 耳语转换按官方 -44.47 LUFS 标定输入；歌词编辑和音乐人声提取按官方 -14 LUFS 与 0.95 峰值保护输出。
- 内容、歌词、情绪、非语言、音质修复和说话人任务会先规范并校验请求，避免合法运行但实际不执行编辑。
- 英文内容/歌词/情绪请求会生成对应的官方英文指令；英文情绪音频可直接填写 `sad`、`fearful` 等标签。
- 本地依赖中包含轻量的 Silero VAD 与响度处理代码，代码更新后无需更换用户的 Python 或模型目录。
- 完整真实回归覆盖 17 个任务入口，并额外对悲伤/恐惧、两种去口音和非语言增加/删除做成对验证。

去口音、悲伤/恐惧情绪及指定说话人的可听效果仍受 AuK 模型本身影响；验证资料保留实际结果，不把不稳定结果标记为确定通过。
